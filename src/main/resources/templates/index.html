Welcome to the Spring Boot Application!

This web interface was created for the coursework assignment of the Java Applications course.

The application includes the following modules and features:

Hungarian National Bank (SOAP)

Retrieve exchange rates through the MNB web service for a specified period, with graphical visualization.

  • Open (MNB)

Forex Client (OANDA API)

Access financial account information, retrieve current and historical exchange rates, and open or close positions at market prices.

  • Open (Forex)

Temperature Converter

A tool for quick conversion between Celsius, Fahrenheit, and Kelvin temperature units.

  • Open (Temp)

Database Management (CRUD)

Create, read, update, and delete records using an H2 database.

  • Open (CRUD)
